# How to Start the FutureTrust Preview

I have already:
1. Linked your API credentials.
2. Written the code for the **Urgency Widget** and **Recent Purchase Popup**.
3. Configured the project for Windows.

### To see the app live:
1. Open your terminal (PowerShell or CMD).
2. Run these commands:
   ```powershell
   cd C:\Users\Hp\.openclaw\workspace\future-trust-app
   npm install
   npx shopify app dev --reset
   ```
3. When prompted, select your **Development Store**.
4. Click the link provided in the terminal to open the app!

I'll be here to help you customize the features once you see it in action.
